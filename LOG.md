# LOG

A running log of everything done to build this repo, in order.

## Decisions so far

 * Secrets are stored unencrypted in a git-ignored `secrets/` directory.
 * The built ISO contains secrets, so it is written into `secrets/` too.
 * The ISO boots non-interactively (no passphrase prompts); physical
   possession of the ISO/USB is the security boundary.
 * The WireGuard private key is prepared uniquely for this image and
   provided by the user (not generated by the build).
 * Scope: a stock Arch installer that comes up online (WiFi via iwd),
   connects to the WireGuard VPN, and runs sshd with baked-in
   `authorized_keys`, so the install can be driven remotely over SSH.

## Install build dependencies

```
sudo pacman -S --needed archiso wireguard-tools qemu-base just
```

 * `archiso` - provides `mkarchiso` and the `releng` profile.
 * `wireguard-tools` - provides `wg` for key inspection on the build host.
 * `qemu-base` - for test-booting the ISO locally.
 * `just` - runs the `Justfile` wrapper around `build.sh` (added later).

## More decisions

 * Profile strategy: the repo holds only our overlay files. The build
   script copies a fresh `releng` profile from
   `/usr/share/archiso/configs/releng` at build time and lays our files
   on top, so we track upstream automatically.
 * Secrets are written in their native formats (iwd `.psk` files,
   wg-quick `wg0.conf`, OpenSSH `authorized_keys`), no templating.
 * sshd listens on all interfaces, key-only authentication.
 * Hostname: `arch-iso`.
 * Wired ethernet is preferred; WiFi is the fallback when there is no
   wired route.

## Notes on the stock releng profile (archiso 91)

 * Networking is `systemd-networkd` + `iwd` + `systemd-resolved`.
 * `20-ethernet.network`, `20-wlan.network`, `20-wwan.network` all
   DHCP, with route metrics 100 / 600 / 700, so ethernet is already
   preferred over WiFi when both are up.
 * `iwd.service` and `sshd.service` are enabled.
 * `/etc/ssh/sshd_config.d/10-archiso.conf` enables root password
   login; root's password is empty, so SSH is unusable by default.
 * `systemd-resolvconf` is already in `packages.x86_64`, so a future
   `DNS =` line in `wg0.conf` will work with wg-quick.
 * `wg-quick@.service` sets `WG_ENDPOINT_RESOLUTION_RETRIES=infinity`
   and orders after `network-online.target` and `nss-lookup.target`, so
   a DNS-name `Endpoint` is retried until it resolves. No override needed.
 * `sshdgenkeys.service` only generates host keys that are missing, so
   baked-in host keys are kept.
 * mkarchiso copies `airootfs/` with `--no-preserve=ownership,mode`:
   everything becomes root-owned with default modes unless listed in
   `file_permissions` in `profiledef.sh`. Every secret needs an entry.
 * archiso 91 builds rootless (via `unshare --map-auto --map-root-user`)
   when the user has `/etc/subuid` and `/etc/subgid` ranges, so no sudo.

## Further decisions

 * WiFi fallback uses the stock route metrics (WiFi may join while wired,
   but ethernet carries traffic). No custom failover logic.
 * SSH host keys are generated once into `secrets/ssh/host/` and baked
   in, so the fingerprint is stable.
 * Build entrypoint: `just build`, which wraps `./build.sh`.

## Scaffold

Repo layout:

```
Justfile                 # just build / just clean
build.sh                 # assembles profile and runs mkarchiso
packages.extra           # appended to releng packages.x86_64
airootfs/                # overlay on top of releng's airootfs
  etc/hostname                                  # arch-iso
  etc/ssh/sshd_config.d/10-archiso.conf         # key-only root login
  etc/systemd/system/multi-user.target.wants/
    wg-quick@wg0.service -> /usr/lib/systemd/system/wg-quick@.service
```

Secrets layout (git-ignored):

```
secrets/
  wifi/<SSID>.psk                 # iwd network files, one per network
  wireguard/wg0.conf              # wg-quick config for this image
  ssh/authorized_keys             # keys allowed to SSH in as root
  ssh/host/ssh_host_*_key[.pub]   # generated by build.sh if missing
  build/                          # transient: staged profile + work dir
  out/                            # built ISOs
```

`build.sh` steps:

 1. Check required secrets exist, and that `wg0.conf` sets
    `PersistentKeepalive` (needed so the peer can reach us through NAT).
 2. Generate SSH host keys into `secrets/ssh/host/` if missing.
 3. Copy releng to `secrets/build/profile/`, overlay `airootfs/`, append
    `packages.extra`, set `iso_name="arch-iso"`.
 4. Install each secret into the profile's airootfs and append a
    `file_permissions` entry for it to `profiledef.sh`.
 5. Run `mkarchiso -v -w secrets/build/work -o secrets/out` rootless.
 6. Remove `secrets/build/`.

## First build (2026-10-24)

```
just build
```

 * First attempt failed: with no WiFi files, `/var/lib/iwd` did not
   exist in the profile, and mkarchiso aborts on a `file_permissions`
   entry for a missing path ("Outside of valid path"). Fix: `build.sh`
   now creates every secret directory before registering it.
 * Second attempt succeeded in ~3 minutes:
   `secrets/out/arch-iso-2026.10.24-x86_64.iso` (1.6G). The
   "Possibly missing firmware" warnings from mkinitcpio are normal.
 * `build.sh` now also sets the ISO to mode 600.
 * Verified inside the image without booting it:

   ```
   bsdtar -xf secrets/out/arch-iso-*.iso arch/x86_64/airootfs.sfs
   unsquashfs -lln arch/x86_64/airootfs.sfs
   ```

   `/etc/wireguard` and `/root/.ssh` and `/var/lib/iwd` are `0/0 700`;
   `wg0.conf`, `authorized_keys` and SSH host private keys are `0/0 600`;
   hostname is `arch-iso`; `wg-quick@wg0.service` is enabled.
